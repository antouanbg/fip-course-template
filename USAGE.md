# Usage

Един ред на сесия с агент. Gemini CLI: `/stats` преди изход → input/output tokens (кешираните токени не се показват при безплатен вход — пропуснете ги). Copilot: показва credits/заявки — пишете ги в колоната Credits. Уеб чат (Claude/ChatGPT): пишете броя prompt-ове в Credits и оставете токените празни. Безплатният план не струва нищо — записвайте колко **би струвала** сесията по публичния ценоразпис на доставчика; под таблицата отбележете кой ценоразпис ползвате.

| Date | Tool | Input tokens | Output tokens | Credits / prompts (if no tokens) | List-price cost |
|---|---|---|---|---|---|

Пример за ред: `| 2026-10-06 | Gemini CLI | 18 400 | 2 100 | | $0.09 |`
