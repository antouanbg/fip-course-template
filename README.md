# Fundamentals of Internet Programming · вашето работно пространство

**Програмиране за Интернет · ТУ-София · 4 курс, зимен семестър 2026/27**

Това repo е вашето работно място за целия курс: Упражнение 1 в `ex1/`, Упражнения 2–5 (проектът) в останалата част. Всичко се изпълнява в браузъра чрез **GitHub Codespaces** — на лаптопа ви не се инсталира нищо.

## Старт (еднократно, ~15 мин)

1. Акаунти: **GitHub** (реално име) и **Google** (за Gemini CLI). Кандидатствайте за [GitHub Student Developer Pack](https://education.github.com/pack) още сега — не е задължително, но дава Copilot Pro и повече Codespaces часове.
2. На страницата на шаблона: **Use this template → Create a new repository**. Направете го **public**, име: `fip-<факултетен номер>` (напр. `fip-121221045`).
3. В новото repo: **Settings → Collaborators** → добавете преподавателя (`antouanbg`).
4. **Code → Codespaces → Create codespace on main**. Първото стартиране отнема няколко минути.
5. Когато терминалът покаже `Workspace ready`: `node --version` трябва да отговори. Стартирайте агента (`gemini` → вход с Google). Отворете `ex1/README.md`.
6. След **всяка сесия с AI агент**: един запис в `AGENT_LOG.md` и един ред в `USAGE.md`.

## AI агент — избирате един

| Вариант | Къде | Бележка |
|---|---|---|
| **Gemini CLI** (препоръчително) | Терминал в Codespaces: `gemini` → вход с Google акаунт (кодът се поставя обратно в терминала) | Безплатно ≈ 1000 заявки/ден. Чете `AGENTS.md` автоматично. `/stats` показва токените. Ако входът „замръзне": Ctrl+C → `npm install -g @google/gemini-cli@latest` → `gemini` |
| **Copilot Chat** | Панелът вдясно в Codespaces | Без Student Pack: ≈ 50 заявки/месец — стига за „второ мнение", не за основна работа. Със [Student Developer Pack](https://education.github.com/pack): Copilot Pro (200 credits/месец). **Кандидатствайте през първата седмица** — одобрението отнема дни. |
| **Claude / ChatGPT** (уеб чат) | claude.ai / chatgpt.com | Copy-paste на файла + `AGENTS.md` в чата. Работи, но агентът не вижда repo-то. |

Инструментът не е важен. Важен е начинът на работа: **вие формулирате, агентът предлага, вие проверявате и отговаряте за всеки ред.**

**Поверителност:** безплатните планове може да ползват заявките ви за обучение на моделите. Никога не давайте на агент лични данни, истински пароли или API ключове. Тайни → `.env` (в `.gitignore`), никога в repo-то или в чата.

## Проверете се, преди да предадете

```bash
node checks/ex1.mjs        # упражнение 1
```

Проверява **структура**, не качество: липсващ раздел, непопълнен лог, `fetch` без обработка на грешки. Минаването е минимумът; оценката се дава на разбора по критериите в заданието.

## Предаване

Push, после tag на commit-а, който предавате, и push на tag-а:

```bash
git tag ex1
git push origin ex1
```

Използвайте `ex1` … `ex5`. По-късен push не променя предаденото.

## Пазете безплатната квота

Спирайте codespace-а, когато приключите (**Code → Codespaces → … → Stop codespace**) и изтривайте старите (спрените също ползват място). Безплатна квота: **120 core-часа/месец** (≈ 60 часа на 2-ядрена машина; 180 със Student Pack), 15 GB. Не сменяйте машината с по-голяма. При изчерпване: заключва се до следващия месец, без такси — **никога не въвеждайте карта**, пишете на преподавателя. Следващите сесии: **Code → Codespaces →** съществуващия, не създавайте нов.

## Правила на курса

- Закъснение над 15 мин — работите с друга група. Присъствие = физическо присъствие **и** изпълнена задача (tag до края на упражнението).
- Заверка: не повече от 1 отсъствие + завършена курсова задача.
- **Ако не можете да обясните кода си ред по ред — не го предавайте.**
