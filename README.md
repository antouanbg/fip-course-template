# Fundamentals of Internet Programming · вашето работно пространство

**Програмиране за Интернет · ТУ-София · 4 курс, зимен семестър 2026/27**

Това repo е вашето работно място за целия курс: Упражнение 1 в `ex1/`, Упражнения 2–5 (проектът) в останалата част. Всичко се изпълнява в браузъра чрез **GitHub Codespaces** — на лаптопа ви не се инсталира нищо.

## Старт (еднократно, ~10 мин)

1. На страницата на шаблона: **Use this template → Create a new repository**. Направете го **public**, име: `fip-<факултетен номер>` (напр. `fip-121221045`).
2. В новото repo: **Settings → Collaborators** → добавете преподавателя (`antouanbg`).
3. **Code → Codespaces → Create codespace on main**. Първото стартиране отнема няколко минути.
4. Когато терминалът покаже `Workspace ready`, отворете `ex1/README.md` и започнете.
5. След **всяка сесия с AI агент**: един запис в `AGENT_LOG.md` и един ред в `USAGE.md`.

## AI агент — избирате един

| Вариант | Къде | Бележка |
|---|---|---|
| **Copilot Chat** (препоръчително) | Панелът вдясно в Codespaces | Работи с GitHub акаунта ви, без допълнителен вход. Безплатен план; с [Student Developer Pack](https://education.github.com/pack) — Copilot Pro. |
| **Gemini CLI** | Терминал: `gemini` | Безплатен лимит с Google акаунт. Чете `AGENTS.md` автоматично. `/stats` показва токените. |
| **Claude / ChatGPT** (уеб чат) | claude.ai / chatgpt.com | Copy-paste на файла в чата. Работи, но по-бавно — няма достъп до repo-то. |

Инструментът не е важен. Важен е начинът на работа: **вие формулирате, агентът предлага, вие проверявате и отговаряте за всеки ред.**

## Какво има тук

| Път | За какво служи |
|---|---|
| `.devcontainer/` | Дефиниция на средата: Node 22, GitHub CLI, Gemini CLI, Copilot Chat, Live Server |
| `AGENTS.md` | Инструкциите, които агентът чете в началото на всяка сесия (`CLAUDE.md` сочи към него) |
| `AGENT_LOG.md`, `USAGE.md` | Дневниците, които водите от Упр. 1 нататък |
| `SPEC.md` | Спецификацията на проекта ви (от Упр. 2) |
| `ex1/` | Упражнение 1: `index.html`, заданието и `PROMPTS.md` |
| `checks/` | Self-check за всяко упражнение: `node checks/ex1.mjs` |
| `.github/workflows/ci.yml` | Пуска тестовете ви при всеки push (от Упр. 3) |

## Проверете се, преди да предадете

```bash
node checks/ex1.mjs        # упражнение 1
```

Проверява **структура**, не качество: липсващ раздел, непопълнен лог, `fetch` без обработка на грешки. Минаването е минимумът; оценката се дава на разбора по критериите в заданието.

## Предаване

Push, после tag на commit-а, който предавате, и push на tag-а:

```bash
git tag ex1
git push origin ex1
```

Използвайте `ex1` … `ex5`. По-късен push не променя предаденото.

## Пазете безплатната квота

Спирайте codespace-а, когато приключите (**Code → Codespaces → … → Stop codespace**), и изтривайте тези, които не ползвате. Безплатната квота е 60 часа/месец на 2 ядра.

## Правила на курса

- Закъснение над 15 мин — работите с друга група. Присъствие = физическо присъствие **и** изпълнена задача (tag до края на упражнението).
- Заверка: не повече от 1 отсъствие + завършена курсова задача.
- **Ако не можете да обясните кода си ред по ред — не го предавайте.**
